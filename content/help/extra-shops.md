---
title: "🏪 臨時店舗を載せたいとき"
type: "help"
---

常設ではない店舗や、大学の管理外の店舗も、Welfare TIME に載せられます。載せた店舗のカードには「臨時」と表示され、大学が営業情報を公開している店舗と区別できます。

載せたい場合は、営業の情報を JSON というファイルの形に書いて、運営者に依頼してください。ここでは、その手順と書き方を説明します。

## 載せるまでの流れ

1. **JSON を書きます。** 書き方は、次の「JSON の書き方」をご覧ください。
2. **GitHub の Issue で依頼します。** [新しい Issue](https://github.com/tamadalab/welfare-time/issues/new) に、書いた JSON を貼り付けてください。GitHub のアカウントが必要です。
3. **運営者が内容を確認して、掲載の準備をします。** 内容に不明な点があれば、Issue で質問します。
4. **サイトに反映されます。** 毎朝7時ごろの更新で反映されます。急ぐ場合は、運営者が手動で更新します。

Issue は誰でも見られる形で公開されます。氏名、電話番号、メールアドレスなどの個人情報は、書かないでください。

## JSON の書き方

営業する日ごとに、1件のエントリを書きます。複数のエントリは、`[` と `]` で囲んで並べます。次の例は、10月15日と16日に営業する店舗です。

```json
[
  {
    "id": "popup-curry",
    "name": "臨時カレー販売",
    "date": "2026-10-15",
    "location": "並楽館前",
    "category": "キッチンカー",
    "headline": "学園祭の準備期間限定",
    "url": "https://example.com/",
    "start_time": "11:00",
    "end_time": "14:00",
    "note": "売り切れ次第終了"
  },
  {
    "id": "popup-curry",
    "name": "臨時カレー販売",
    "date": "2026-10-16",
    "location": "並楽館前",
    "category": "キッチンカー",
    "headline": "学園祭の準備期間限定",
    "url": "https://example.com/",
    "start_time": "11:00",
    "end_time": "13:00",
    "note": "売り切れ次第終了"
  }
]
```

### 項目

| 項目 | 必須 | 書き方 |
| --- | --- | --- |
| `id` | 必須 | 店舗を区別する名前です。半角の英小文字、数字、ハイフンだけで書きます（例：`popup-curry`）。同じ店舗は、すべての日で同じ `id` にします。 |
| `name` | 必須 | カードに表示する店名です。 |
| `date` | 必須 | 営業する日を `2026-10-15` のように書きます。 |
| `location` | 必須 | 営業する場所です。次の「場所の書き方」をご覧ください。 |
| `start_time`、`end_time` | 必須 | 営業の開始と終了の時刻を、`11:00` のように書きます。 |
| `category` | 任意 | 「食堂」「ショップ」「コンビニ」「サービス」「ATM」「キッチンカー」から選びます。省略すると「ショップ」になります。 |
| `headline` | 任意 | 店名の下に表示する、ひとことの紹介です。 |
| `url` | 任意 | 店舗の案内ページです。`https://` で始まるものを書きます。書くと、カードを押したときに開きます。 |
| `business_hours` | 任意 | 営業時間の表記を変えたいときに書きます。省略すると、`11:00～14:00` のように開始と終了の時刻から作ります。 |
| `note` | 任意 | カードに表示する備考です。 |

### 場所の書き方

`location` を地図上の建物の名前で書き始めると、その建物にカーソルを合わせたときに、カードと地図が連動します。たとえば「並楽館前」「真理館1F」のように書きます。

地図上の建物は、次のとおりです。

> 並楽館、天地館、10号館、真理館、雄飛館、ピロティ、万有館、本館、神山天文台、サギタリウス館、12号館、神山ホール、4号館、13号館、6号館、5号館、11号館、第1研究室棟、中央図書館、第2実験室棟、第2研究室棟、第1実験室棟、16号館、9号館、第3研究室棟、第4研究室棟、第5研究室棟、15号館、14号館、第6研究室棟、温室棟

学外など、この中にない場所で書き始めたときは、地図の連動はなく、「この店舗はマップ外です」と表示されます。

### 書くときの注意

- 文字は、半角のダブルクォーテーション `"` で囲みます。項目と項目の間にはカンマ `,` が要りますが、各エントリの最後の項目の後には付けません。
- 項目の中に `<` と `>` は使えません。
- 書式に誤りがあるエントリは、読み飛ばされて掲載されません。運営者が確認して、Issue でお知らせします。

## 掲載のあとで

- **営業時間や場所が変わったとき：** 同じ `id` と `date` で、新しいエントリを Issue で伝えてください。その日の掲載が、新しい内容に置き換わります。
- **営業をとりやめたとき：** 取りやめる店舗と日付を、Issue で伝えてください。
- **掲載する内容について：** 掲載する店舗の情報は、依頼された内容にもとづいています。大学が確認したものではありません。内容によっては、掲載をお断りすることがあります。
